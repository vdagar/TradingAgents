# TradingAgents India (Copilot)

A team of AI agents analyzes a stock for you inside VS Code: market, sentiment, news and fundamentals analysts, bull and bear researchers, a trader, three risk debaters and a portfolio manager. They run on your **GitHub Copilot** models, so no OpenAI or Anthropic key is needed.

Built for Indian markets (NSE/BSE) and works for US stocks too. A fork of [TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents).

> **Not investment advice.** Output is generated by language models from public data and can be wrong. NSE publishes its data for information and learning, not for commercial use ([terms](https://www.nseindia.com/nse-mcp)); screener.in, rbi.org.in and the news sites have their own terms.

## Use

In Copilot Chat:

```
@tradingagents /analyze RELIANCE
@tradingagents TCS.NS 2026-11-03 market,news
```

- A bare ticker is an NSE code in the IN market (`RELIANCE` runs as `RELIANCE.NS`); `500325.BO`, `^NSEI` and other suffixed symbols keep their form.
- The date defaults to today; the analysts default to the `tradingagents.analysts` setting.
- The two manager agents use the model picked in the chat's model menu; the other ten use `tradingagents.quickModel`.
- Progress streams into the chat; the decision is shown at the end with links to the full report, saved under `tradingagents-reports/<ticker>/<date>/` in your workspace.

One analysis makes roughly 30 to 80 model requests, counted against your Copilot plan. A research depth above 1 makes more.

## First run

The extension sets itself up once, in its own storage folder: it downloads [uv](https://github.com/astral-sh/uv) (pinned version, SHA-256 checked), installs Python 3.12 and the bundled TradingAgents package with its dependencies from PyPI. This takes about a minute and needs internet access. Your system Python is not touched.

## Data

| Data | Source |
|---|---|
| Prices | NSE MCP server, Yahoo Finance fallback |
| Fundamentals | screener.in, Yahoo fallback |
| Insider trades, shareholding, pledges, filings, option chain | nseindia.com |
| News | Economic Times, Business Standard, Yahoo |
| Social | r/IndianStreetBets, r/IndiaInvestments, r/DalalStreetTalks |
| Macro | rbi.org.in (rates, MPC, weekly statistics), FRED |
| Global cues | world indices, USD/INR, US yields, crude, gold, FII/DII flows, GIFT Nifty |

## Settings

| Setting | Default | |
|---|---|---|
| `tradingagents.market` | `IN` | `IN` (NSE/BSE) or `US` |
| `tradingagents.quickModel` | `gpt-5-mini` | Copilot model for the ten quick agents |
| `tradingagents.analysts` | all four | analysts run when a request names none |
| `tradingagents.researchDepth` | `1` | debate rounds: 1, 3 or 5 |
| `tradingagents.outputLanguage` | `English` | report language |

**TradingAgents: Set API Key** stores an optional FRED or Alpha Vantage key in VS Code's encrypted secret storage.

## How it works

The agents are Python. For each run the extension starts a local endpoint on `127.0.0.1` (random port, per-run token) that speaks the OpenAI chat API and answers through VS Code's Language Model API, then runs the agents against it. The endpoint closes when the run ends or is stopped.
